# Font Court

> Unused fonts take the stand and demand licensing, deletion, or tribute.

A desktop tool scans your installed fonts and turns each one into a witness with personality, last-use evidence, and courtroom demands. You rule each font innocent, guilty, or sentenced to probation with a project assignment.

## Features
- Scan installed fonts and last-used metadata where available
- Generate font testimonies from style, family, and usage history
- Assign verdicts: keep, delete, archive, or assign to a project
- Export a cleanup plan with font family recommendations

## Stack
- Tauri
- Rust
- SQLite

## Getting started
```
Install Node dependencies with `npm install`, then start the desktop app with `npm run tauri dev`.
```
